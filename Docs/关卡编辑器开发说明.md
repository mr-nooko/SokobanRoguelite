# 关卡工作台开发说明

适用版本为 UE 5.5.4。工作台位于现有 SokobanRoguelite 工程。

## 使用路径

1. 打开 GridWorkbench 地图。打开「窗口 → 推箱子关卡编辑器」。默认读取地图中唯一的 关卡预览。
2. 如果地图有多个预览 Actor，选中目标 Actor 后点「读取预览」。通过 Actor 的 关卡草稿 选择旧草稿，或点「新建草稿」创建并绑定资产。
3. 选画笔，再点格子。放置会替换目标格已有的墙、碎墙、箱子或敌人。使用起点和终点画笔移动对应标记。墙或实体仍可与起终点坐标形成草稿冲突，修正布局警告后再试玩。旋转只改变现有尖刺箱或射线敌人的朝向。
4. 「保存草稿」保存当前 Data Asset。新建草稿后另存地图，才能保留 Actor 对该资产的引用。点 Play 试玩。结束试玩后继续编辑。
5. 组合模块可用「打开草稿属性」编辑，改完点「读取预览」。棋盘上方有「撤销」和「重做」，也可用 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。按钮使用 UE 共享编辑历史，操作后会刷新面板和 3D 预览。整次连续摆放、右键移动和结构摆放各占一条历史。顶部「保存草稿」为绿色，底部「验证关卡」为蓝色，棋盘上的「撤销」为琥珀色，当前工具以青色标示。

## 模块职责

SokobanWorkbench 是 Editor 模块，负责 Slate 网格、工具菜单、事务和资产保存。SokobanRoguelite 提供 UGridLevelAsset、AGridScene 和草稿试玩。SokobanRules 提供 FLevel、模拟、布局检查及双阶段验证。Editor 模块依赖运行时模块，运行时模块向下依赖规则层。

## 棋盘尺寸与常用设置

右侧属性中的「关卡设置」可输入棋盘宽、高（每边 1～64 格），按回车提交输入后点「应用棋盘尺寸」。左上角坐标固定。扩大时新增格子默认铺地板，原有格子与挖空形状保留。缩小不能裁掉起点、终点、墙、碎墙、箱子、尖刺或敌人，违规则显示第一个越界位置。外框裁掉的挖空格从草稿清除，可撤销此次调整。

同一栏可以配置射线地形遮挡，或点「打开草稿属性」编辑箱子与敌人的专属参数。棋盘上方提供「紧凑」「标准」「放大」三个显示档位，缩放仅影响当前面板。修改关卡设置会清除旧验证结果，点「保存草稿」写入资产。

## 棋盘形状

在左侧「棋盘形状」选择「挖空」或「补地板」，再点格子。新草稿默认铺满外框。可以挖掉外角做成 L 形，也可以挖掉中间做成有缺口的房间。已有物件、尖刺和起终点要先移开。改动会刷新 3D 预览，支持撤销重做和保存草稿。
 
## 大力士推箱上限

右侧属性的「关卡设置」里的「大力士推箱上限」用于修改当前草稿的 StrengthLimit，提交时须为正整数。这个值是每次使用道具可推动的箱子数。底部「验证用背包」中的「大力士个数」是道具库存。上限支持撤销重做，保存草稿后持久化，并随关卡数据进入试玩和求解。修改上限后旧验证结果会清除。

## 资产管理与验证

- 「已保存关卡」下拉列出资产注册表中已落盘的关卡草稿，打开时刷新，资产以包路径区分。选中后点「载入所选」可绑定当前预览，点「定位所选」可在内容浏览器查看。重命名或移动资产使用 UE 内容浏览器。
- 「复制当前」以当前草稿创建新资产，并分配新的文件名和关卡编号。草稿保存后进入列表。另存地图可持久化绑定。草稿存在合法性问题时仍可保存。
- 每次编辑后刷新静态布局警告。「验证关卡」先检查布局，再执行两阶段求解。真实资源默认取项目开局库存，可在结果区为当前模拟覆盖。能力预算和道具解锁按项目设置读取。预设开局库存和能力预算均为大力士药丸 1、时空回溯药丸 2。本项目默认每阶段预算为 16 步和 10000 节点。全局合法性最低解法数默认为 1。工作台通过「关卡合法性校验设置」打开项目设置。未证明的结果显示「未确定」。
- 验证背包只用于当前面板的验证，Play 试玩仍采用现有固定背包。编辑棋盘、切换草稿或修改验证库存后清除旧验证结果。

## 面板布局

顶部显示关卡编号、草稿资产、尺寸和未保存状态，提供读取、新建和保存操作。左侧把工具分为起终点与地形、箱子与敌人、编辑操作。中央棋盘显示当前工具与零基行列号。格子以文字和颜色区分物件，多件物品重叠时显示「重叠」，悬停可查看坐标和内容。棋盘支持横向和纵向滚动。底部固定显示检查结果，警告较多时可单独滚动。草稿参数和预览对象的属性详情也使用中文显示名，原有 C++ 字段和资产引用沿用现有标识。

## UE 编辑器扩展组件

关卡说明和赠药使用草稿资产的原生属性面板。策划通过「打开草稿属性 → 关卡说明与通关奖励」编辑多行说明及两种药丸数量，保存后可直接进入草稿试玩检查文字和结算。生成关使用序列的空位默认配置，难度分段可按需覆盖。

- **Editor 模块**。SokobanWorkbench 在项目描述中声明为 Editor 类型，由编辑器 Target 加载。模块启动时注册工具入口，卸载时移除。
- **ToolMenus**。扩展关卡编辑器的「窗口」菜单，添加「推箱子关卡编辑器」。菜单项调用标签页入口。
- **FGlobalTabmanager 与 SDockTab**。注册并创建可停靠标签页，使面板能作为 UE 编辑器的一部分打开。
- **Slate**。SCompoundWidget 承载面板。SVerticalBox、SHorizontalBox、SBorder 和 SBox 划分顶部、工具栏、棋盘和检查区。SGridPanel 和 SButton 实现工具选择与点格，STextBlock 显示状态，SScrollBox 提供滚动。
- **编辑器选择与视口刷新**。GEditor 的 USelection 用于定位当前选中的关卡预览对象，AGridScene::RefreshEditorPreview 和编辑器视口重绘负责同步 3D 场景。
- **资产创建和保存**。AssetTools 与 UDataAssetFactory 创建 UGridLevelAsset，UEditorLoadingAndSavingUtils 保存资产包。地图中的预览对象引用通过保存地图持久化。
- **撤销重做**。FScopedTransaction 和 UObject::Modify 记录编辑，FEditorUndoClient 在撤销或重做后刷新预览。
- **中文标签**。LOCTEXT 和 FText 用于面板文字，UPROPERTY 和 UFUNCTION 的 DisplayName 元数据用于属性详情和编辑器按钮，内部字段名可保持稳定。

## 验收

先做 UE Editor Development 编译，再检查窗口菜单能打开面板。在工作台用墙画笔点一个空格，确认 2D 与 3D 均更新，再做撤销与重做。放一个尖刺箱并旋转，确认面板箭头和 3D 朝向一致。保存草稿后重载确认数据仍在。构造终点占用冲突时应显示布局问题，草稿依然能保存，Play 会拒绝该布局。

当前版本通过按钮和坐标格编辑。地图资源移动或改名应通过 UE 内容浏览器处理。

## 批量摆放与结构库

在工作台选择画笔，输入宽和高。鼠标停在棋盘上会显示预览范围。可以点击左上格摆放，也可以按住左键沿棋盘拖动。经过的有效落点会高亮，松开后提交整笔，撤销一次即可恢复。宽 1、高 4 向下铺四格，宽 4、高 1 向右铺四格。整块修改进入一次 UE 撤销事务。起点、终点和旋转按单格执行。每个落点单独检查画笔范围。落点越界时跳过该落点，保留同一笔里的其他有效落点。普通画笔可以替换草稿里的墙、箱子和敌人，结构摆放会保护已有物件。

在空格按住右键拖框可选中已有组件。按住 Ctrl 后右键单击或拖框可补选，框到箱体或尖刺端都会选中整只尖刺箱。松开 Ctrl 后右键拖动任一已选组件即可平移整组。右键拖动未选中的单个组件时会改为单独移动。墙、碎墙、箱子、敌人和起终点均可移动，朝向、实体编号和模块参数会保留。整组通过占格检查后一起提交，允许占用本组移开后腾出的位置。只要一处落点冲突、挖空或越界，整组留在原位。

「复制组件」和 Ctrl+C 将选中的墙、碎墙、箱子和敌人存入当前工作台的临时剪贴板。用「粘贴组件」或 Ctrl+V 进入摆放状态，左键选择选区左上角，可多次粘贴，Esc 退出。切换草稿后仍可粘贴。复制复用结构的占格与摆放接口，保留组件间距、尖刺朝向、射线方向和模块参数，为副本分配独立编号。起点和终点会跳过。落点被占用、挖空或越界时整组取消摆放。一次移动或粘贴各占一条 UE 撤销记录。

点击「记录结构」后，在棋盘上按住左键拖框。松开即保留选区，再次直接拖框会替换选区，按住 Ctrl 拖框或单击可补选。确认选区后填写可选名称并点击「保存选区」。资产保存到内容浏览器的 `/Game/Maps/Structures`，重名加后缀。可通过资产选择器查找、定位并选择已保存的结构。点击「摆放结构」，选择目标左上格。可连续摆放同一结构，点击普通画笔即可退出。

## 工作区与草稿查找

左侧「创建组件」提供画笔、批量摆放与结构库。中间是棋盘、缩放和编辑历史。右侧上方按类型、实体编号或坐标筛选组件，单击列表项可滚动定位并高亮对应格。也可在棋盘按 Ctrl+左键检查组件。记录结构模式下，Ctrl+左键仍用于补选。

右侧下方显示所选组件的坐标与编号，可就地旋转有朝向的组件，并配置箱子的沿推动方向弹射和爆炸选项。也可直接选「弹射箱」画笔。弹射箱没有方向序列或格数上限。属性修改会刷新 3D 预览并写入撤销历史。关卡尺寸、射线遮挡和美术配置也在右侧属性区。

顶部草稿库支持按名称或路径检索。唯一结果可用回车载入，也可从列表选择后点击「载入所选」。「试玩关卡」直接启动 UE 试玩，当前预览对象须是场景里唯一开启「用于试玩」的对象。

## 关卡浏览器

点击工作台顶部「关卡浏览器」，可按缩略图浏览已保存的草稿，并按名称或路径筛选。单击卡片查看放大的俯视棋盘、关卡编号、尺寸、组件数量和静态布局检查结果。缩略图按草稿中的格子生成。双击卡片或点击「载入关卡」会把该草稿绑定到当前预览对象。也可在 UE 内容浏览器中定位资产。

浏览器顶部输入名称并点击「新建文件夹」，可在当前目录下创建 UE 内容文件夹。打开文件夹或点击「上一级」切换目录。「在此新建草稿」在当前目录创建并载入草稿，完成后用「保存草稿」写盘。根页保留全部草稿，子目录只展示当前目录的草稿和直接子目录。

新建和复制草稿时输入资产名称，工具提供可编辑默认值并拒绝同目录重名。浏览器可删除选中的草稿，删除前会列出引用它的序列和位置。可取消后先替换引用，也可确认强制删除。
