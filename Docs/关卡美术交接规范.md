# 关卡美术交接规范

适用范围为 UE 5.5.4 主工程的关卡工作台。美术配置是独立资产，草稿引用配置，多个草稿可共用一份配置。关卡的占位、碰撞、射线、伤害和可解性由 FLevel 与规则层决定。

## 工作台入口

1. 打开「窗口 → 推箱子关卡编辑器」，载入关卡草稿。在右侧「美术表现」选择已有配置，或点「新建配置」创建并绑定。
2. 点「打开配置」，在「按用途配置外观」展开对应项。可直接选择静态网格和材质，也可从内容浏览器拖入。在引用字段旁点放大镜可定位源资产，双击资产可进入原生资产编辑器。「在内容浏览器定位」可快速找到整份配置。
3. 保持工作台打开，修改配置时会刷新当前关卡的 3D 预览。保存美术配置以保留资源参数，保存草稿以保留绑定。已有地图绑定新的草稿时另存地图。
4. 同一配置被多个草稿引用时，修改会影响这些草稿。制作关卡变体时，可在内容浏览器复制配置，再将副本绑定到目标草稿。单独复制关卡草稿会沿用原配置引用。

## 项目默认配置

右侧「美术表现 → 打开项目默认配置」可打开 /Game/Art/Profiles/DA_BoardDefault。地板的深浅材质、整墙和碎墙、三种板条箱、果冻弹射箱以及终点粒子都已登记为可编辑引用。未绑定美术配置的关卡会自动使用这份资产。自定义配置中填写的资源优先，空槽继承默认值。

## 资源槽和交付限制

- 可替换地板、墙、碎墙、普通箱、尖刺箱、爆炸箱、弹射箱、独立尖刺、接触敌人、射线敌人、终点和光束。弹力炸弹箱的底座继承「弹射箱」槽的果冻模型、材质和变换，并在上方保留爆炸标记。单独组合爆炸和尖刺时，箱体用爆炸箱槽，尖刺仍独立使用尖刺槽。
- 每槽可以指定静态网格、材质槽 0 覆盖、局部偏移（厘米）和缩放倍率。指定网格而材质留空时，使用该网格自带材质。网格和材质都留空时，继承项目默认配置。地板可配置交错材质。勾选「按单格尺寸自动贴地」可将导入网格对齐原有棋盘占位。
- 棋盘单格边长为 125 cm。静态网格建议以约 100 cm 的居中占位体为初始参考，再通过该槽的局部偏移和缩放对齐。墙、箱体、射线发射口与尖刺不得靠外观误导占用区域。射线敌人自定义网格的前向为 +X。光束自定义网格沿 +Z 轴，建议保持 100 cm 轴向长度和 Z 缩放倍率 1，让端点与实际遮挡一致。
- 终点粒子可替换材质，材质应提供 Glow 向量和 Fade 标量参数，使用适合粒子面片的透明或加色混合方式。角色骨骼与步态继续走 Manny 的动画资源流程。

## 命名与验收

配置默认在 /Game/Art/Profiles 下按 DA_GridArt 命名，工具在重名时生成后缀。新增环境网格建议用 SM_Grid_<用途>_<风格>，材质实例用 MI_Grid_<用途>_<风格>。资源移动与重命名通过内容浏览器完成，以维护引用。

交付前在同一张关卡切换默认和自定义配置，核对格子落点、尖刺方向、光束遮挡端点、终点辨识度和粒子淡出。随后用相同动作序列试玩，确认表现切换保持规则结果一致。

## 关卡音效

从关卡编辑器的美术配置入口打开对应资产，在「音效」中为移动、推箱、推动失败、击杀敌人、爆炸、倒放、死亡和通关选择 Sound Wave 或 Sound Cue。支持 UE 可赋给 USoundBase 的音频资产。未配置的项目保持静音。

推箱成功时播放推箱音效，同次行动的同类事件只播放一次。死亡和通关音效在倒地或终点粒子表现开始时播放。保存美术配置后进入试玩检查；编辑器里摆放物件时保持静音。
