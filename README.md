# 推箱子战斗 Roguelite

使用 Unreal Engine 5.5.4 制作的 3D 俯视角推箱子玩法原型。玩家用箱子阻挡射线、触发机关，并走到终点。工程包含关卡工作台、运行时关卡编辑器，以及可混排手工关和生成关的关卡序列。

## 打开工程

1. 在 Windows 上使用 Git 克隆仓库，安装 Epic Games Launcher 版 **UE 5.5.4**。
2. 双击 [SokobanRoguelite.uproject](SokobanRoguelite.uproject)。仓库随附三个 Win64 编辑器模块和模块清单。引擎的 `Engine/Binaries/Win64/UnrealEditor.modules` 使用构建 ID `37670630` 时，可直接打开，无需编译 C++。
3. 在启动页面点「播放游戏」进入玩法，或点「打开关卡编辑器」进入工作台。也可以通过 UE 的「窗口 → 推箱子关卡编辑器」打开工作台。

首次打开可能需要编译着色器。若 UE 提示 C++ 模块版本不匹配，先核对引擎版本和构建 ID。需要重新编译时，保存并关闭编辑器，再运行 [BuildEditor.cmd](BuildEditor.cmd)。

## 编辑与试玩

查看[关卡编辑器功能介绍视频](关卡编辑器功能介绍视频.mp4)，可从仓库下载后在本地播放。

- **关卡策划**可以新建和浏览草稿、批量摆放和移动组件、复用结构，并在属性里配置提示文字和通关赠药。
- **美术**可以通过关卡美术配置替换组件模型、材质、音效和特效，再从同一草稿检查实际表现。
- **关卡验收**可在工作台用指定背包校验草稿。正式切关会以玩家累计后的实际背包校验下一关，通过后才进入。

## 打包 Windows 游戏

运行 [PackageWindows.cmd](PackageWindows.cmd)，默认输出到 `Saved/Packages/Windows`。把完整的打包目录发给试玩者即可，他们可以直接运行游戏，无需安装 UE。
